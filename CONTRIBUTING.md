# Contributing to SourceGuard

Contributions are welcome.

## Areas for contribution

- Additional source verification strategies
- Improved evidence extraction
- Better authority classification
- Freshness detection
- User interface development
- Testing
- Documentation
- GenLayer integration improvements

## Development Principles

Contributions should preserve the distinction between:

- Nondeterministic interpretation
- Validator verification
- Deterministic state changes

Changes involving consensus-sensitive logic should include appropriate tests.

## Pull Requests

Please explain:

1. What was changed.
2. Why the change is needed.
3. How it was tested.
4. Whether the change affects consensus behavior.

## Reporting Issues

Please provide:

- A clear description
- Steps to reproduce
- Expected behavior
- Actual behavior
- Relevant transaction information when available
